# HR-Analytics
HR Data Analytics Project:  took the real dataset, performed the data analysis in Power BI and created a Dashboard consist of different visuals.
# HR Analytics Dashboard

## Project Overview
Built an HR attendance analytics dashboard using Power BI.

## Tools Used
- Power BI
- Power Query
- Excel

## Features
- Attendance analysis
- WFH trends
- Leave tracking
- Employee performance insights

## Data Transformation
- Combined multiple monthly sheets
- Unpivoted attendance columns
- Cleaned and transformed date fields
